Seguridad y privacidad

Compromiso con la protección de datos y uso responsable. Este proyecto es educativo y no recopila información personal.

🔒

Proteccion de datos personales

La aplicacion minimiza datos personales y solo usa los necesarios para autenticar cuenta y guardar continuidad de chat.

💬

Guardado de conversaciones

Si inicias sesion, tus conversaciones se guardan en tu cuenta para continuidad. Si usas modo invitado, se guarda solo en sesion local del navegador.

📖

Uso educativo y general

Este proyecto está diseñado exclusivamente para fines educativos. El contenido proporcionado es orientación general sobre hábitos saludables, no constituye consejo médico profesional.

⚕️

El asistente no sustituye a un médico

Kyrbi ofrece información educativa sobre hábitos saludables. No realiza diagnósticos, no prescribe tratamientos y no sustituye la consulta con profesionales de la salud. Si tienes síntomas o preocupaciones médicas, consulta con un adulto responsable y un profesional.

🌐

Tecnología utilizada

La aplicación utiliza HTML, CSS y JavaScript estándar. No requiere conexión a internet para funcionar (excepto para cargar la página inicial). No utiliza cookies de seguimiento ni servicios de análisis de terceros.

👥

Responsabilidad del usuario

Los usuarios son responsables de usar la información de manera apropiada. Se recomienda consultar con padres, tutores o profesionales de la salud antes de realizar cambios significativos en hábitos alimentarios, de ejercicio o de sueño.

Preguntas frecuentes

¿La aplicación guarda mis conversaciones?
No. Las conversaciones se almacenan solo en la memoria temporal del navegador (sessionStorage) y se eliminan al cerrar la sesión.

¿Necesito crear una cuenta?
No. La aplicación no requiere registro ni autenticación. Funciona de forma anónima.

¿Puedo confiar en las recomendaciones de Kyrbi?
Kyrbi proporciona orientación educativa general. Para decisiones importantes sobre salud, siempre consulta con un profesional.

¿La aplicación funciona sin internet?
Una vez cargada, la aplicación puede funcionar sin conexión. Sin embargo, necesitas internet para cargar la página inicial.

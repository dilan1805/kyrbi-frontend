Evaluación del proyecto

Criterios de evaluación para jueces y evaluadores. El proyecto se enfoca en claridad, utilidad y experiencia del usuario.

🎯

Facilidad de uso

La interfaz está diseñada para ser intuitiva. Navegación clara, botones con propósito definido y flujo lógico sin fricciones.

  • Navegación multipágina clara y accesible
  • Asistente Kyrbi con modos visibles y explicados
  • Interfaz responsive en todos los dispositivos
  • Accesibilidad: skip links, ARIA labels, contraste adecuado
📚

Claridad de la información

Contenido educativo estructurado, sin jerga médica. Información práctica y accionable para estudiantes de 13-15 años.

  • Hábitos explicados de forma simple y directa
  • Asistente con respuestas contextuales según el modo
  • Lenguaje apropiado para la edad objetivo
  • Separación clara entre educación y consejo médico
✨

Experiencia del usuario

Diseño premium que transmite seriedad y profesionalismo. Sensación de producto real, no demo visual.

  • Diseño moderno y profesional
  • Paleta de colores coherente (azul marino + verde)
  • Transiciones suaves y feedback visual
  • Experiencia conversacional fluida con Kyrbi

Aspectos técnicos destacables

Arquitectura: Código modular sin frameworks, listo para integrar IA real. Separación clara entre UI, lógica y configuración.

Preparación para producción: El motor de respuestas (kyrbi-engine.js) puede reemplazarse fácilmente por llamadas a API real. La estructura de estado y mensajes está diseñada para escalar.

Responsive: Diseño adaptativo que funciona en móviles, tablets y escritorio. Navegación móvil con menú hamburguesa.

Seguridad y privacidad

  • No se recopilan datos personales.
  • No se guardan conversaciones.
  • Uso educativo y general.
  • El asistente no sustituye a un médico.
